브라우저에서 바로 하는 미니 아케이드 게임 모음. 설치 없이 링크만 열면 된다.

**▶ https://leebong-su.github.io/arcade/**

| 게임 | 바로가기 |
|---|---|
| 테트리스 | https://leebong-su.github.io/arcade/tetris/ |
| 벽돌깨기 | https://leebong-su.github.io/arcade/breakout/ |

최고 점수는 게임별로 브라우저(localStorage)에 저장되고 허브 화면에도 표시된다.

## 테트리스 (`tetris/`)

가이드라인 규칙을 따르는 정통 테트리스.

- **SRS 회전**과 월킥, 7-bag 랜덤, 홀드, 고스트, 다음 블록 5개 미리보기
- 고정 유예 0.5초(바닥에서 움직이면 리셋, 최대 15회)
- 점수: 싱글 100 / 더블 300 / 트리플 500 / 테트리스 800 × 레벨
- **T-스핀**(3-코너 규칙, 미니 구분), **백투백** ×1.5, 콤보, 퍼펙트 클리어 보너스
- 10줄마다 레벨업, 레벨 20까지 낙하 속도 증가

| 키보드 | 동작 |
|---|---|
| `←` `→` | 이동 (누르고 있으면 연속 이동) |
| `↓` | 소프트 드롭 |
| `↑` / `X` | 회전 |
| `Z` | 반대 회전 |
| `Space` | 하드 드롭 |
| `C` / `Shift` | 홀드 |
| `P` / `Esc` | 일시정지 |
| `M` | 소리 켜기/끄기 |

터치: 좌우로 끌기 = 이동, 탭 = 회전, 아래로 끌기 = 소프트 드롭, 아래로 휙 = 하드 드롭, 위로 휙 = 홀드. 화면 아래 버튼으로도 조작할 수 있다.

## 벽돌깨기 (`breakout/`)

- 조작: 마우스 / 터치 드래그 / `←` `→` (또는 `A` `D`), 발사는 클릭 · 탭 · `Space`
- 일시정지 `P`(또는 `Esc`), 소리 `M`

| 캡슐 | 효과 |
|---|---|
| **W** | 와이드 패들 (15초) |
| **M** | 멀티볼 — 공 하나가 셋으로 (최대 12개) |
| **S** | 슬로우 (10초) |
| **P** | 관통볼 — 강철 빼고 다 뚫고 지나감 (8초) |
| **+1** | 목숨 추가 |

1~5레벨은 직접 디자인한 맵이고, 6레벨부터는 레벨 번호를 시드로 좌우대칭 맵을 자동 생성한다. 벽돌 내구도는 1~3(점 개수로 표시)이고 회색 강철 벽돌은 안 깨진다. 패들에 닿지 않고 연속으로 깨면 콤보 배율이 올라간다(5콤보마다 x1, 최대 x5).

## 구조

```
index.html          # 허브 (게임 목록)
tetris/index.html   # 테트리스 (Canvas 2D + WebAudio, 파일 하나)
breakout/index.html # 벽돌깨기 (Canvas 2D + WebAudio, 파일 하나)
```

빌드 도구나 외부 라이브러리는 없다.

```bash
# 로컬 실행
python3 -m http.server 8000
# → http://localhost:8000
```

테스트용 파라미터:

- 공통: `?auto`(자동 플레이, 점수 저장 안 함), `&ts=4`(배속, 최대 8)
- 벽돌깨기: `&level=N`(시작 레벨)
- 테트리스: `?debug`(회전·T-스핀 검증용 `window.__tdbg`)
