# 🧱 Arcade

브라우저에서 바로 하는 미니 아케이드 게임 모음. 설치 없이 링크만 열면 된다.

## 벽돌깨기 (Breakout)

**▶ 플레이: https://leebong-su.github.io/arcade/**

- 조작: 마우스 / 터치 드래그 / `←` `→` (또는 `A` `D`)
- 발사: 클릭 · 탭 · `Space`
- 일시정지 `P`(또는 `Esc`), 소리 켜고 끄기 `M`
- 최고 점수는 브라우저(localStorage)에 저장된다.

### 파워업

| 캡슐 | 효과 |
|---|---|
| **W** | 와이드 패들 (15초) |
| **M** | 멀티볼 — 공 하나가 셋으로 (최대 12개) |
| **S** | 슬로우 (10초) |
| **P** | 관통볼 — 강철 빼고 다 뚫고 지나감 (8초) |
| **+1** | 목숨 추가 |

### 레벨

- 1~5레벨은 직접 디자인한 맵, 6레벨부터는 레벨 번호를 시드로 좌우대칭 맵을 자동 생성한다.
- 벽돌 내구도 1~3(점 개수로 표시), 회색 강철 벽돌은 안 깨진다.
- 패들에 닿지 않고 연속으로 깨면 콤보 배율이 올라간다(5콤보마다 x1, 최대 x5).

## 구조

빌드 도구나 외부 라이브러리 없이 `index.html` 하나(Canvas 2D + WebAudio)로 되어 있다.

```bash
# 로컬에서 실행
python3 -m http.server 8000
# → http://localhost:8000
```

테스트용 파라미터: `?auto`(자동 플레이), `&level=N`(시작 레벨), `&ts=4`(배속, 최대 8).
